# fahadimran7/tap

Homebrew tap for [Pill](https://www.fahadimran.me/pill), a floating scratchpad for macOS that pastes.

```sh
brew install --cask fahadimran7/tap/pill
```

Update with `brew upgrade --cask pill`. Remove with `brew uninstall --cask pill`, or
`brew uninstall --zap --cask pill` to also delete your items and settings.

The cask is bumped automatically by Pill's release script. This repo's
[releases](https://github.com/fahadimran7/homebrew-tap/releases) hold the downloads: each one has
`Pill-<version>.dmg`, which the cask pins, and `Pill.dmg`, behind the website's
[latest download](https://github.com/fahadimran7/homebrew-tap/releases/latest/download/Pill.dmg).
